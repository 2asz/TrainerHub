# Trainer Hub · 修改器整合

> English version: [README.md](README.md)

把风灵月影、本地修改器统一管理的绿色版桌面工具：
**登记 → 搜索 → 一键启动 → 自动检测游戏 → 官网下载**。

![image-20260817033417945](assets/image-20260817033417945.png)

## 快速开始

1. 双击 `启动.bat`
   - 首次运行：自动创建虚拟环境（`.venv`）并安装依赖，约 1-3 分钟，只需一次；
   - 之后每次：无窗口直接启动软件。
2. 首次打开会自动扫描桌面 `game` 文件夹里的 Steam 快捷方式并导入游戏库。
3. 为游戏添加修改器（手动添加 / 扫描文件夹 / 官网下载），然后一键启动。

> 绿色版说明：软件不写注册表、不装系统服务，删除整个软件文件夹即完全卸载，
> 不污染系统 Python 环境（依赖全部隔离在项目内 `.venv`）。
>
> 提示：首次启动初始化（清理 + 离线封面生成）在后台线程执行，窗口不卡；
> 首次打开自动导入桌面快捷方式为并行版，几十个几秒完成。

## 移植性（换电脑直接用）

**方式一：源码绿色版**（当前项目）
- 整个项目文件夹拷到新电脑，双击 `启动.bat` 即可（新电脑需装 Python，首次自动装依赖）。
- 游戏库、修改器目录、封面缓存都随文件夹一起走。

**方式二：绿色版（免装 Python）**
- 从 **GitHub Releases** 页面下载 `TrainerHub-<版本>-green.zip`（发布时随 Release 提供），
  解压后双击 `TrainerHub.exe` 即可用，无需安装 Python。
- 数据（游戏库、封面、修改器目录）自动在 exe 旁生成，随文件夹整体拷贝。
- 自行打包（改代码后）：`.\venv\Scripts\python -m PyInstaller --noconfirm --clean TrainerHub.spec`

## 功能

| 功能 | 说明 |
| --- | --- |
| 游戏库 | 卡片墙展示游戏（Steam 封面），支持搜索、按来源分类（风灵月影/本地/无修改器） |
| 导入游戏 | 自动解析桌面 `.url`/`.lnk` 快捷方式（**多线程并行**，几十个几秒完成）；Steam 游戏自动获取中文名和封面 |
| 启动 | 单点启动游戏、启动修改器（管理员权限，弹 UAC 属正常）、一键"游戏+修改器"联动 |
| 运行检测 | 游戏运行时卡片自动高亮"运行中" |
| 扫描修改器 | 扫描任意文件夹，按关键字（Fling/Trainer/修改器/小辛…）自动识别并入库 |
| 官网下载 | 内置风灵月影官网适配器：搜索 → 下载 → 自动解压 → 入库（best-effort） |
| 检查更新 | 自动检查官网下载修改器的新版本（支持中文游戏名），更新后自动清理旧版文件 |
| 一键刷新 | 重新检测运行状态、清理已删除的修改器记录、重新生成/重试封面 |
| 离线封面 | 无官方封面时自动生成 exe 图标 / 首字母封面（不依赖网络） |
| 界面主题 | 深色 / 浅色两套主题，设置里一键切换，即时生效 |
| Defender 白名单 | 一键将修改器目录加入 Windows Defender 排除项，避免误报 |

## 修改器目录结构

```
trainers/
├── 风灵月影/<游戏名>/    ← 从官网下载的自动归这里
└── 本地/<游戏名>/        ← 手动添加/扫描的
```

## 安全与免责声明

- **启动确认策略**：本软件从官网下载的修改器，**首次启动需一键确认**（并展示 SHA-256），
  确认后同款直接启动；你自己添加的本地修改器不受影响。
- **下载域白名单**：仅允许从 `flingtrainer.com`（HTTPS）下载；下载后计算 SHA-256 存档备查。
- **解压防护**：自动拒绝压缩包内 `../`、绝对路径等越界条目（zip-slip 防护）。
- **无遥测、无自动更新**：不收集任何数据，仅本地审计日志记录下载/启动事件。
- **仅限单人游戏**：本软件仅面向单机游戏使用场景。
- **杀毒软件误报**：修改器本质是修改游戏内存的程序，Windows Defender 等可能误报，属正常现象。
  请将 `trainers` 目录加入杀毒软件白名单（软件内提供一键加入 Defender 排除项），
  且**只从官网下载修改器**，不要运行来源不明的文件。
- 本软件只负责"登记 / 启动 / 下载"，不包含任何破解或注入代码。

## 常见问题

**Q: 第一次双击没反应？**
A: 首次运行会弹出命令行窗口显示安装进度，请耐心等待依赖装完（约 1-3 分钟）。
若报"未找到 Python"，请先安装 [Python 3.10+](https://www.python.org/downloads/) 并勾选
`Add python.exe to PATH`。

**Q: 启动修改器弹 UAC 提权窗口？**
A: 正常。修改器需要管理员权限读写游戏内存，这是 Windows 的安全机制。

**Q: 官网下载失败/找不到游戏？**
A: 官网改版或防护升级时自动下载会失效（best-effort 功能）。此时可手动打开官网复制链接，
用「手动添加」将下载好的修改器加入库，核心功能不受影响。

**Q: 某款修改器在中文路径下运行异常？**
A: 极少数老修改器只认纯英文路径。可在「设置」中把目录命名改为英文，或把该修改器复制到
英文路径后添加。

## 开发

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```
